# Security reports

Report suspected vulnerabilities privately through this repository's **Security → Report a vulnerability** form. Include the version or commit, what you found, and enough detail to reproduce it. Please don't put vulnerabilities in public issues or include someone else's credentials or personal data.

Pixelody is still in testing. Fixes target the latest commit on `main` and the latest tagged release; I can't promise a response time. File access, pairing, the local host service, updates and packaging are all in scope.
