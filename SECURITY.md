# Security policy

Pixelody is still in testing. Security fixes go to the latest commit on `main` and the latest tagged release. I’ll take a look when I can, but I can’t promise a response time.

## Report a vulnerability privately

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Include what you found, how to reproduce it, and which version or commit you tested.

Do not include other people's personal data or credentials in a report.

## Scope

Pixelody plays local audio files and can pair with a companion app over the local network. Reports about pairing, the local host server, file access, and the update and packaging process are in scope.
